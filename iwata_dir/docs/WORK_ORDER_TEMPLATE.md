手順進捗の正本HTMLと担当台帳の変更は、候補の統合担当へ差分を返し、並列の作業者が正本を直接確定させない。別のSTATEファイルや会話の要約を新たな正本にしない。

## Codex中心の開発と、現在への案内の点検

D-130に従い、Codexを仕様検討・調査・文書・実装・検査の中心にする。担当製品を変えること自体を必須工程にせず、能力・権限は今回実際に使う範囲で確認する。旧役割案や過去の保存手順を、今回の許可・未確認の能力の代わりにしない。

現在の方針・状態を変えた場合は、その要約、次の操作、未確定一覧、関係する案内も点検する。過去コマンド・報告値・基準SHAは当時の記録として保ち、現在の案内だけを担当する編集元へ接続する。本体着手前の規範監査はT-014の有限な受入条件で区切り、未検証の科学・環境まで完了扱いにしない。
