# Balloon Lab N04 PoC（独立デモ）

## 起動（Windows PowerShell）
1. ZIPを展開して、`index.html` と `grid.js` があるフォルダを開く。
2. そのフォルダのエクスプローラーのアドレスバーに `powershell` と入力して Enter。
3. `python -m http.server 8774` を実行。
4. `http://127.0.0.1:8774/` をブラウザで開く。終了は PowerShell で Ctrl+C。

**このPoCは既存のBalloon Labのソースコードや飛行計算/GFS処理を一切変更しません。** 地図の表示にはインターネット（Leaflet CDN・OpenStreetMapタイル）が必要です。探索地点は概念上の飛行計算開始座標であり、放球許可や安全を示しません。

## 動作確認
- 「矩形を描く」→ 地図上2点 →「地点を生成」。青い格子点が表示される。
- 「多角形を描く」→ 3点以上 →「多角形を確定」→「地点を生成」。多角形内だけ格子点を生成する。
- 「手動で地点追加」→ 地図をクリック → 橙色の点を選択。
- 選択した地点に名前を入力して「選択地点を保存」→ 緑色になる。
- ブラウザを再読み込み → 探索エリア・地点・選択状態が復元される。
- 「作業中の地点を消去」→ 保存済み地点のみ残る。

## 実装範囲と保留事項
- 自動生成は探索エリア外接矩形の縦横比に応じた目標点数（広く25/標準64/詳しく144）を使います。これらは**使い勝手確認用の暫定値**であり、最適解を表しません。実際の点数は多角形の形状で変わります。最大200点/生成。
- 緯度経度からのkm距離は簡易球面近似。境界ぎりぎりの厳密な地理測量には向きません。180度経線を跨ぐ領域は非対応。
- 永続化先はこのブラウザ内の localStorage。現在は作業状態も保存され、明示的なリセットまで残ります。別ブラウザ・PCとの同期なし。計算結果や気象情報は保存しません。
- N05/N06以降の探索日時・上昇速度・シミュレーション実行・結果表示は未実装。

## ロジックの自動テスト
Node.jsが入っていれば `node test_grid.js` を実行。地図操作・保存復元はブラウザ手動確認が必要。
